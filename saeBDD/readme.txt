Voici comment lancer le projet et tester la base de données :

1. Ouvre ton terminal (ou invite de commande) dans ce dossier.
2. Si ce n'est pas déjà fait, installe Flask en tapant : pip install flask
3. Lance le mini-serveur en tapant : python app.py
4. Ouvre ton navigateur web et va à l'adresse : http://127.0.0.1:5000
